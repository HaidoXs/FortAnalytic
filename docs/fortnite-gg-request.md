# Demande à fortnite.gg — accès aux images des îles

À envoyer via le formulaire de contact / Discord / e-mail de fortnite.gg. Remplace les `[crochets]` avant d'envoyer.

---

**Objet : Permission request – island thumbnails for a small Fortnite analytics site**

Hi fortnite.gg team,

I'm [Prénom], a [UEFN creator / developer] working on **FortAnalytic** ([URL du site, ou "not public yet"]), a small analytics site for Fortnite Creative and UEFN islands. It uses Epic's public Fortnite Data API for player counts, genre rankings and trends.

That API has no island images, and fortnite.com pages can't be read by a server, so our island lists only show generated placeholder thumbnails. Your island pages include each island's official Discover image (hosted on Epic's CDN), and I'd like to ask whether we could use them, in one of these ways:

1. **An API or data export** with island code → image URL, if you offer one (free or paid, I'm happy to discuss terms).
2. **Permission to read your public island pages** (`fortnite.gg/island/{code}`) with a clearly identified bot:
   - User-Agent: `FortAnalytic/0.1 (+[URL ou e-mail de contact])`
   - Only the islands we track (about 1,300, Epic's genre top 100s), each read **once a week**
   - At most **1 request per second**, results cached on our side
   - We would only keep the image URL (Epic's CDN), not your data or stats

Today these requests are stopped by your Cloudflare challenge, and we haven't tried to get around it — we'd rather ask. If you agree to option 2, could you allow our User-Agent (or tell us what you'd prefer)?

We'd be glad to credit fortnite.gg on every page that shows these images, with a link back to your island pages.

Thanks for your time, and for the great site!

[Prénom]
[E-mail / Discord]
[URL du site]

1. via **une API ou un export** code d'île → URL d'image (gratuit ou payant, ouvert à la discussion) ;
2. ou en **autorisant la lecture de vos pages d'îles** par un bot clairement identifié (`FortAnalytic/0.1 (+contact)`), uniquement pour les ~1 300 îles suivies, une fois par semaine, 1 requête/seconde maximum, en ne gardant que l'URL de l'image.

Aujourd'hui ces requêtes sont bloquées par votre protection Cloudflare et nous n'avons pas cherché à la contourner. Si l'option 2 vous convient, pourriez-vous autoriser notre User-Agent ?

Nous créditerions fortnite.gg avec un lien sur chaque page affichant ces images.

Merci !
